context: "TrAIT is a gamified upper-limb stroke rehabilitation system developed with UBC clinical researchers. The task was originally clinically validated using a Kinect sensor in a published trial (Neurorehabilitation and Neural Repair, reporting ~13% improvement in paretic arm function). I was brought on as sole engineer to rebuild the system in Unity with Ultraleap hand tracking for the next generation of clinical research."
decision: "I rebuilt the architecture in Unity from scratch around a clean GameManager and scene controller structure, integrating Ultraleap hand tracking with keyboard fallback, multi-stage workspace calibration with error protection, and streak-based adaptive difficulty. I also built the automated research telemetry pipeline: per-tick CSV session logs emailed directly to the lab, and a ScriptableObject config pipeline with generated C# accessors."
outcome: "Delivered the complete Unity/Ultraleap rehabilitation software suite and telemetry pipeline for ongoing clinical trials, succeeding the Kinect version validated in Neurorehabilitation and Neural Repair (13% arm-function gain)."
